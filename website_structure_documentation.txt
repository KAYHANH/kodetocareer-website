        * "Placements" -> links to `/placements`
        * "Career Services" -> Hover triggers a custom dropdown:
          - "Admissions Support" -> links to `/career-services/admissions`
          - "Placement Services" -> links to `/career-services/placements`
          - "Service Overview" -> links to `/career-services`
        * "Blog" -> links to `/blog`
        * "Contact" -> links to `/contact`
     3. Action Buttons (Right-aligned):
        * "Login" (Ghost style, grey border) -> redirects to `/login`
        * "Start Learning" (Primary blue gradient) -> redirects to `/signup`
     4. Mobile Hamburger Button (`lg:hidden`):
        * Toggles a full-height slide-in drawer on mobile viewports.
        * Mobile Drawer (`AnimatePresence` + Framer Motion slide-in from right):
          - Solid dark background.
          - Lists all navigation links, an accordion containing all 10 courses, 
            and centered CTA buttons ("Login" and "Start Learning").
